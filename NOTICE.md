# Авторство

Репозиторий не содержит звуков. Скрипты `tools/build_*.py` собирают звуковые банки из
**Salamander Grand Piano V3** (Yamaha C5), автор **Alexander Holm**, лицензия **Creative Commons Attribution (CC-BY)**.
Исходные файлы публикуются на https://freepats.zenvoid.org/Piano/SalamanderGrandPiano/ (там же текст лицензии).

Собранные этими скриптами файлы `.sf2` — производные работы. Если вы их распространяете, указывайте:

> Salamander Grand Piano V3 by Alexander Holm, CC-BY. Преобразовано в SF2 (уменьшено по числу слоёв громкости,
> длине хвостов, выровнено по уровню).

Из набора используются нотные сэмплы (`A0v1.wav` …), шумы отпускания клавиш (`rel*.wav`), резонанс струн (`harm*.wav`) и
педальные звуки (`pedal*.wav`). Поправки строя взяты из `SalamanderGrandPianoV3Retuned.sfz` (Markus Fiedler).
